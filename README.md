# Edge AI-Based Smart EV Charging Station

An intelligent EV charging station integrating Edge AI, ESP32, real-time monitoring, predictive charging analytics, MQTT communication, and ThingsBoard cloud visualization.

## 🚗 Project Overview

This project focuses on developing a smart EV charging station capable of monitoring multiple charging bays and making intelligent charging and load-management decisions.

## ⚡ Key Features

- Real-time voltage and current monitoring
- Power and energy monitoring
- Charging bay status detection
- Temperature monitoring
- Smart load management
- Overload detection
- Dynamic charging control
- Predictive arrival probability
- Predicted charging duration
- MQTT-based communication
- ThingsBoard cloud telemetry and visualization

## 🛠️ Technologies Used

- ESP32
- C/C++
- PlatformIO
- MQTT
- ThingsBoard
- ArduinoJson
- PubSubClient
- Wokwi
